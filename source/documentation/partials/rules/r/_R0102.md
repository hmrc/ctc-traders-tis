**Functional Description**

Data item &lt;INVALIDATION.Decision&gt; can contain 2 valid values:<br>
- '0' = 'No': Invalidation refused by Customs: Decision<br>
- '1' = 'Yes': Invalidation accepted by Customs: Decision
